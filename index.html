Source, IDs, and previous snapshots

This dataset contains cities, villages, and other localities from Poland’s National Register of Geographical Names (PRNG). Coordinates describe representative points, not boundaries or addresses. Official source.

IDs and data updates

The id field contains the official PRNG record ID. Sorting or filtering does not change it. Releases through v0.4.0 used row numbers; those old IDs cannot be used to join new data. GUGiK can change or remove source records.

The page shows the source export date and the last successful check. A source check does not mean the records have changed. Updates are published after validation.

License and file formats

Data: GUGiK, Państwowy Rejestr Nazw Geograficznych (PRNG), CC BY 4.0. Converted by Polish geonames. Keep this attribution when you use or share the data.

CSV and TSV protect text cells that begin with spreadsheet formula characters. Arrays and objects use JSON text in CSV, TSV, and XLSX. JSON and GeoJSON retain nested values.
