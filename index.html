03 / KNOW YOUR SOURCE

Official records.
Open possibilities.

Data comes from Poland’s National Register of Geographical Names (PRNG), maintained by GUGiK. This project makes that register easier to explore and download.

Visit the official source ↗
What is included?

The full locality register: cities, villages, settlements, hamlets, and named parts of localities. Source name statuses are preserved. Coordinates refer to representative points, not locality boundaries or street addresses.

How current is the data?

Each snapshot shows the actual source export date and the last successful check. Data updates are published after validation. A new check does not mean the source has changed.

What changed about IDs?

The id field now contains the official PRNG record ID. It remains the same when you sort or filter records. Releases through v0.4.0 used row numbers; those old IDs cannot be used to join new data. Source records can still be changed or removed by GUGiK.

License and attribution

Data: GUGiK, Państwowy Rejestr Nazw Geograficznych (PRNG), CC BY 4.0. Converted by Polish geonames. Keep this attribution when you use or share the data.

CSV and TSV protect text cells that begin with spreadsheet formula characters. Arrays and objects are stored as JSON text in CSV, TSV, and XLSX. Use JSON or GeoJSON to retain nested values.
