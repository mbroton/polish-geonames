Data source

This dataset contains cities, villages, and other localities from Poland’s National Register of Geographical Names (PRNG), maintained by GUGiK.

Read about the official register or download the source GML archive.

Coordinates and IDs

Coordinates use WGS 84 and describe representative points for localities. They do not describe boundaries or street addresses.

The id field contains the official PRNG record ID. Sorting or filtering does not change it. GUGiK can change or remove source records.

Data updates

The source export date shows the date of the published dataset. The check date shows when the upstream source was last checked successfully. A check does not mean the records have changed. Updates are published after validation.

File formats

JSON and GeoJSON retain nested values. CSV, TSV, and XLSX store arrays and objects as JSON text. CSV and TSV protect text cells that begin with spreadsheet formula characters. GeoJSON always includes point coordinates, even if you do not select latitude and longitude as columns.
